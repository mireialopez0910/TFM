In order to create a new application, it is necessary to follow the following steps, to create a strong foundation.

This diagram shows the ideal development process for a project. Since the application developed is the first version, requirements retrieval should only happen once, and the project should finish with the Release phase, once all tests have been passed correctly.
\smallskip\\For the development of the application, it has been decided to use a hybrid structure, using Object Oriented Programming (OOP) with C\# and Matlab scripting.
\smallskip\\The main advantages of using C\# with OOP are that it allows the code to be reusable, organised and easy to maintain \cite{profile_OOP}. In this project, it has been used for the development of the Graphical User Interface and the controllers for both, web services and Matlab script management.
\smallskip\\On the other hand, Matlab provides a specialised environment for numerical calculations, simulations, and complex data analysis\cite{matlab}. Working directly with matrices and arrays makes the data processing and visualisation easier and more efficient.
\smallskip\\Keeping all the Matlab-scripts execution inside the application will also help the analyisis of the results of the corresponding plots by keeping the enviroment and tools offered by Matlab, which are the ones used in the present.
\smallskip\\Having the Matlab code in the execution directory also offers the possibility to update the different scripts in case it is needed in the future. One exemple of this would be the modification of the different file formats or the desire to add a new parameter in any plot. For the final user, which is the UPC research group, not knowing how the application works would not be a stopper for the adaptation of the code.
