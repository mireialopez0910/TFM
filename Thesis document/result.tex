\subsection{Work-flux}
The final work-flux for working with GRASP algorithm can be summarised in the following steps, all included in the developed application and executed in CALCULA environment:
\begin{enumerate}
    \item Create, open or import a project: Load a project in order to save downloaded data and output data and figures in a defined directory.
    \begin{figure}[H]
        \centering
        \includegraphics[width=16cm]{img/Execution/Home.png}
        \caption[Home screen]{\footnotesize{Home screen}}
        \label{fig:Home}
    \end{figure}
    \item Download files: Select date range and station and download the corresponding files. Available files will be shown in same View.
    \begin{figure}[H]
        \centering
        \includegraphics[width=16cm]{img/Execution/FilesDownloaded.png}
        \caption[Files downloaded]{\footnotesize{Files downloaded}}
        \label{fig:FilesDownloaded}
    \end{figure}
    \item Combine data: Select the desired MeasureID, choosing the data and time range to be used. Heights can be configured and available configurations will be automatically shown. 
    \begin{figure}[H]
        \centering  
        \includegraphics[width=16cm]{img/Execution/OptionsEnabled.png}
        \caption[Data combination with enabled options]{\footnotesize{Data combination with enabled options}}
        \label{fig:OptionsEnabled}
    \end{figure}
    \item Execute GRASP: Send data will create the input files automatically for GRASP algorithm and will execute it. 
    \item Plot results: Available results will be automatically detected. If possible, list of figures will be created and saved in Output directory. The user will be able to choose which figure to show.
    \begin{figure}[H]
        \centering
        \includegraphics[width=16cm]{img/Execution/plotted.png}
        \caption[Plotted figure]{\footnotesize{Plotted figure example}}
        \label{fig:Plotting_plotted}
    \end{figure}    
\end{enumerate}
\subsection{Transparent implemented features}
With the objective of having an enhanced user experience, different features have been implemented in the application. These features are not noticeable for the user, but they improve the application's performance and functionality. 
\begin{enumerate}
    \item Actris-Earlinet measurements are automatically filtered between Download step and Data Combination step. Measurements taken during night time (without sun radiation) are not useful for GRASP algorithm, so the corresponding option is automatically removed from Data Combination options and cannot be sent to GRASP. 
    \item Matlab scripts in Data combination have been corrected and optimised. 
    \begin{itemize}
        \item File detection has been corrected to the expected format.
        \item Data names and structure inside Matlab namespace have been corrected to more general cases.
        \item Error detection has been enhanced for missing data in empty files.
        \item Configuration detection has been corrected.
        \item Interpolation has been implemented for VD data. It prevents GRASP errors and gives a wider measurement range for the algorithm execution.
        \item Endings without ";" have been detected and corrected, in order to give a cleaner Matlab execution.
    \end{itemize}
    \item All directories used during execution are defined in Settings and can be modified. This allows the user to configure the application to their needs.
    \item Matlab scripts in Plotting have been corrected and optimised.
    \begin{itemize}
        \item Wrong figure legend have been corrected in several figures.
        \item Title detection has been detected in order to show correct Station name, without relying on file structure. File structure can be modified from data providers and may be obsolete with time. Station is now detected from Measure ID and passed as configuration parameter.
        \item Endings without ";" have been detected and corrected, in order to give a cleaner Matlab execution.
        \item Remove warnings.
    \end{itemize}
\end{enumerate}

In some tests, it has been detected that all actions cannot be executed in a low resolution system.
